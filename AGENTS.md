# AGENTS.md

Instructions for agents (and contributors) working in this repository.

## Content Must Be Generic

This is a public, shareable plugin marketplace. Nothing in it — code, tests, docs, fixtures, examples, comments — may reference:

- A specific company or employer name
- A specific organization's internal system, tool, or project name (e.g. an internal monorepo name)
- Any individual's real name, username, email, or local filesystem path tied to a specific person or company

Use neutral placeholders instead.

Before adding any test fixture, example, or sample path, ask: would this still make sense if copied into an unrelated company's repo? If not, generalize it.
